# Kanyikan Windows 快速安装说明

## 安装前准备

- Windows 10 或 Windows 11 64 位系统。
- Windows PowerShell 5.1 或更高版本。
- Docker Desktop 已启动，并切换到 Linux Containers。
- 至少 4 个 CPU 核心、8 GiB 内存和 20 GiB 可用磁盘空间。
- 确认本机端口 `10443` 未被其他程序占用。

离线安装不需要互联网。请完整解压发行 ZIP，不要只复制其中部分文件，也不要修改解压后的文件。

## 一键安装

双击 `install.cmd`，或在发行目录中运行：

```powershell
.\kanyikan.ps1 install
```

安装器会要求输入并确认管理员密码。密码至少 16 个字符，不会显示在终端或日志中。

安装器随后会询问是否信任本机独立根证书。输入 `TRUST` 表示同意将该证书加入当前 Windows 用户的受信任根证书存储；拒绝不会阻止服务启动，但浏览器会显示证书警告。

安装成功后的唯一入口为：

```text
https://127.0.0.1:10443
```

LLM、搜索和监控服务不属于安装启动条件。首次登录后，请在设置页完成任务执行所需的 Provider 配置。

## 常用命令

```powershell
.\kanyikan.ps1 status
.\kanyikan.ps1 start
.\kanyikan.ps1 stop
.\kanyikan.ps1 restart
.\kanyikan.ps1 doctor
.\kanyikan.ps1 backup
.\kanyikan.ps1 restore -Backup ".\data\backups\<备份目录>"
.\kanyikan.ps1 update -Package "<离线更新 ZIP>"
.\kanyikan.ps1 support-bundle
.\kanyikan.ps1 uninstall
```

`backup` 会备份数据库、快照和 Skill。请另行安全保存 `config/system.env`；该文件包含解密本机 Provider 配置所需的密钥，安装器日志和支持包不会收录它。

默认卸载会保留配置、备份和四个数据卷。只有明确运行下列命令并完成两次确认时，才会永久删除本项目数据：

```powershell
.\kanyikan.ps1 uninstall -PurgeData
```

## 更新与回滚

更新仅接受官方离线 ZIP。版本必须严格高于当前版本，并明确声明支持从当前版本升级。

更新前会自动创建并校验完整保护备份。新版本只有在全部服务健康、管理员登录和核心 API 冒烟检查通过后才会被记录为当前版本。

- 退出码 `71`：更新失败，但数据库、旧发行资产和旧服务均已自动恢复健康，可以继续使用旧版本。
- 退出码 `72`：自动回滚未完整通过，入口会保持停止；不要继续写入，请保留保护备份和更新事务并按支持包处理。
