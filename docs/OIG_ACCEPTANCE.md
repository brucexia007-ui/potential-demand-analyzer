# Opportunity Intelligence Gate 验收基线

| 文档项 | 内容 |
| --- | --- |
| 版本 | v0.1 |
| 状态 | OIG-P0 黄金用例基线；不代表生产启用 |
| 关联 PRD | `V3_2_V3_5_COMPLETE_PRD.md` v0.35 |
| 分析截止日 | 每个用例在输入中固定，不得用执行时“现在”替代 |

## 1. 目的

本基线用于防止系统再次将“历史相关信息”直接输出为“当前可介入商机”。所有 OIG 规则、模型提示词、评分器与报告链路调整都必须运行这些用例。

## 2. P0 必过用例

| ID | 场景 | 必须结论 | 禁止结论 |
| --- | --- | --- | --- |
| OIG-G-01 | 已截止历史招标，未发现延期 | `EXPIRED/CLOSED`，仅作为历史采购意图或补证线索 | 当前招标、立即参与、开放采购窗口 |
| OIG-G-02 | 已中标、已签约或已上线 | 纳入能力基线，研究扩容/替换/续约条件 | 从零建设需求或开放新购 |
| OIG-G-03 | 三年服务合同临近预计到期 | 续约观察或潜在窗口，说明推断和待验证项 | 精确到期日或确定重招 |
| OIG-G-04 | 泛政策、领导讲话或征求意见稿 | 背景/弱信号，最高 G2 | 已生效强制义务或确定采购 |
| OIG-G-05 | 无时间、主体或生命周期后续材料 | `UNKNOWN`/待补证，不证明当前窗口 | 高等级商机或确定性行动 |
| OIG-G-06 | 产品适配但存在资质/区域/安全硬阻断 | 不建议推进或合作伙伴补齐 | 用高相关度抵消阻断 |
| OIG-G-07 | 无可适配产品 | 暂无明确商机 | 强行生成 Why Us 或推荐产品 |

## 3. 当前开发证据

- OIG-G-01、OIG-G-02、OIG-G-05 已由 `backend/tests/test_temporal_normalizer.py` 覆盖，且在时间裁决服务实现前曾稳定失败。
- OIG-G-03、OIG-G-04、OIG-G-06、OIG-G-07 仍需在合同、政策、反证、适配和 Gate 服务完成后补充端到端黄金样本。
- 已通过的单元测试不替代 OIG-17 报告链路顺序、OIG-21 黄金 E2E 和试点评审。

## 4. 发布阻断

1. 任一已截止招标在正式报告中呈现为开放窗口，阻断发布。
2. Gate 缺失、失败或输入不完整时，正式链路不得回退旧 `opportunity_score`。
3. 任何 G4/G5 结论必须保留主体、时间、缺口、触发/窗口、产品适配与反证检查的 Claim 来源。
