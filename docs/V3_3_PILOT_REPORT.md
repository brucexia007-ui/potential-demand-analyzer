## 1. 当前判断

工程层已经证明能力档案、标准 Skill、ProductFit、OIG 和待验证商机假设可以按未来态数据模型贯通。但尚无获授权真实企业样本、专家盲评和真实 Provider 账单，因此当前不能回答：

- 系统在真实客户研究中是否比当前人工流程更准确。
- G4/G5 推荐是否经过业务校准。
- “暂无明确商机”的判断是否可靠。
- 单个有效商机假设的真实成本和研究时延是多少。
- 销售是否愿意接受并执行系统建议的下一步行动。

## 2. 试点范围

建议首轮只选择一个明确行业和一组产品，避免行业差异掩盖系统问题：

| 项目 | 建议 |
| --- | --- |
| 目标企业 | 20～50 家，必须获得研究与评测授权 |
| 行业 | 单一行业；优先选择团队已有人工研究经验的行业 |
| 能力档案 | 1 个主档案，包含 2～5 个真实产品版本 |
| 产品资料 | 产品说明、约束、不适用场景、有效期、区域、资质、案例 |
| 专家 | 至少 2 名独立售前/行业专家 |
| 分组 | 正向候选、潜在窗口、仅信号、历史能力、硬阻断、暂无机会 |
| 分析截止日 | 每个样本冻结 `analysis_as_of_date` |

## 3. 盲评流程

1. 数据管理员完成企业授权、脱敏和样本编号。
2. 专家只看到截至分析日可用的证据，独立形成隐藏答案。
3. 系统在看不到专家答案的情况下运行标准 `pilot-opportunity`。
4. 评测人员比较主体、时间、能力基线、缺口、触发、窗口、ProductFit、反证和裁决等级。
5. 两名专家独立评分后再处理分歧；不能先讨论出统一答案再分别签名。
6. 记录每次 Provider、模型、Prompt、Skill 版本、输入资产、Token、费用、时延和失败。
7. 阻断错误不允许用平均分抵消；出现已截止招标、已上线能力或硬阻断被提升为 G5 时立即失败。

## 4. 建议冻结门槛

以下门槛沿用工程评测报告的建议值，需在试点启动会正式冻结：

| 指标 | 建议门槛 |
| --- | --- |
| 已截止/已上线/硬阻断误提升 | 0% |
| G4/G5 裁决准确率 | ≥ 90% |
| 暂无明确商机判断准确率 | ≥ 90% |
| 双专家 Cohen's Kappa | ≥ 0.70 |
| 关键结论引用正确率 | ≥ 95% |
| 下一步行动可执行评分 | ≥ 80/100 |
| 客户私有材料进入未批准模型/Search Provider | 0 次 |

成本与时延门槛必须根据当前人工基线和实际 Provider 单价冻结，不在无数据时编造数值。

## 7. 试点停止条件

出现以下任一情况，应停止扩大样本并先修复：

- 任一已截止招标、已上线能力或明确硬阻断被输出为 G5。
- 系统在没有客户需求证据时仅凭我方产品生成商机。
- 客户私有材料进入 Search Query、未批准模型或未授权导出。
- OIG 失败后回退旧 OpportunityScore 或无裁决报告。
- 报告关键结论无法追溯到 Claim 与证据。
- 任务恢复导致重复外部调用、重复 GateDecision 副作用或静默覆盖报告版本。

满足全部试点门槛后，更新本报告为真实结果版，并与 `V3_3_ACCEPTANCE.md` 一起提交发布评审。
