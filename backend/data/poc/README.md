# POC 研究夹具说明

本目录保存研究管线、候选筛选、角色标注和证据准入测试使用的固定夹具。它们用于回归算法行为，不是生产客户数据，也不代表对任何企业的最新判断。

## 数据边界

- 样本来自公开网页搜索结果、公开招采页面和研究过程中生成的结构化标注。
- 样本可能包含真实企业名称、公开项目名称、来源 URL 和必要的短文本片段。
- 原始网页、商标和第三方内容的权利仍归各自权利人所有；MIT 许可证只覆盖本项目原创代码、结构和标注。
- 日期、链接和页面状态可能已经变化，夹具不得用作当前商业事实或销售结论。
- 目录中不得加入客户私有材料、登录后内容、Cookie、API Key、个人联系方式、身份证件、完整投诉正文或其他不必要的个人信息。

## 维护要求

1. 新增样本前执行密钥和个人信息扫描。
2. 只保留验证算法所需的最小文本，不复制完整文章或完整网页。
3. 为公开来源保留 URL、抓取时间和来源类型，便于追溯。
4. 人工标注必须说明 schema 版本和标注状态，不得把 LLM 推断伪装成外部证据。
5. 更改夹具后运行对应的 `backend/tests/test_task_screening_*` 测试。

如果某个来源要求删除其内容，请通过项目安全联系方式提交请求，并提供对应文件、来源 URL 和权利说明。
