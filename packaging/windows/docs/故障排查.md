# Kanyikan Windows 故障排查

## 首先运行

```powershell
.\kanyikan.ps1 status
.\kanyikan.ps1 doctor
.\kanyikan.ps1 support-bundle
```

`status` 和 `doctor` 是只读命令。支持包只包含白名单诊断信息，并在交付前执行敏感信息扫描；它不会收录 `system.env`、证书私钥、业务正文、数据库、快照或 Skill 内容。

## 常见问题

### Docker 不可用

确认 Docker Desktop 已启动，并处于 Linux Containers 模式。安装器不支持 Windows Containers，也不会联网拉取缺失镜像。

### 端口 10443 被占用

关闭占用 `127.0.0.1:10443` 的其他程序后重试。如果这是同一份 Kanyikan 安装已启动的入口，使用当前安装目录中的命令管理服务，不要复制出第二份安装目录。

### 浏览器显示证书警告

安装时只有输入精确文本 `TRUST` 才会信任本机根证书。证书仅写入当前 Windows 用户的 Root 存储。默认卸载会删除由安装状态精确记录的该证书信任。

### 安装中断

保留当前目录和数据卷，重新运行 `install`。安装器会从最后一个成功状态继续，并重新验证文件、镜像、配置、证书和服务；不要删除 `state/install-state.json` 或数据卷来强制重装。

### 备份或恢复失败

不要删除没有 `VALID` 标志的失败备份现场。恢复只接受 `data/backups` 内、版本和发行信任元数据与当前安装一致的完整备份。

恢复失败时入口保持停止，恢复前保护备份会被保留。先生成支持包，再人工核对磁盘、Docker 和保护备份。

### 更新失败

- 退出码 `70`：更新包、版本或迁移路径不允许；未进入更新破坏阶段。
- 退出码 `71`：自动回滚成功且旧版本健康；继续使用旧版本并提交诊断包。
- 退出码 `72`：自动回滚不完整；入口保持停止，禁止继续写入。

## 退出码

| 退出码 | 含义 | 建议 |
|---:|---|---|
| 10 | 参数、命令或当前状态不允许 | 按终端提示修正命令 |
| 20 | Windows 或 PowerShell 不受支持 | 使用 Windows 10/11 x64 和 PowerShell 5.1+ |
| 21 | Docker Desktop、Engine 或 Compose 不可用 | 启动 Docker Desktop 并切换 Linux Containers |
| 22 | CPU、内存、磁盘、端口或目录不满足要求 | 释放资源或端口后重试 |
| 30 | 签名、清单或文件摘要失败 | 重新获取官方完整发行包 |
| 31 | 镜像归档、摘要、ID 或平台失败 | 重新获取发行包并检查 Docker |
| 40 | 配置、密钥或管理员密码失败 | 保留现有配置，按提示重试 |
| 41 | 本地证书生成或复核失败 | 检查 Docker 与证书目录权限 |
| 50 | Compose 启停失败 | 运行 `status` 和 `doctor` |
| 51 | 健康检查失败或超时 | 保留容器现场并生成支持包 |
| 60 | 完整备份创建或最终校验失败 | 检查磁盘、数据库和数据卷 |
| 61 | 恢复失败 | 使用恢复前保护备份人工处理 |
| 70 | 更新包或迁移不允许 | 换用合法递增且支持当前版本的包 |
| 71 | 更新失败但自动回滚成功 | 继续使用旧版并提交诊断包 |
| 72 | 更新失败且回滚不完整 | 保持入口停止并人工恢复 |
| 80 | 卸载或永久清理失败 | 仅按状态证明的资源边界处理 |
| 90 | 状态损坏或内部错误 | 停止写操作，从有效备份恢复状态 |

日志位于安装目录的 `logs`。终端失败信息会给出本次日志路径；只读命令或持久副作用前失败时会明确显示未创建日志。
