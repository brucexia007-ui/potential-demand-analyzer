## 1. 评测边界

本轮建立的是脱敏合成、但保持真实售前语义的工程黄金集，用于阻止规则、Skill、Gate 和评分器回归。它验证确定性业务裁决，不调用真实搜索、模型或客户数据，也没有伪造人工专家评分。

因此必须区分：

1. **工程盲对照**：测试执行时只向裁决函数传入场景输入，执行完成后才读取 `expected` 对照结果。本轮已完成。
2. **人工专家盲评**：两名以上售前/OIG 专家在不知道黄金答案的情况下独立判断，再与系统及彼此比较。本轮尚未执行。
3. **真实 Provider 质量、成本和时延评测**：需要授权的模型、搜索、抓取及业务样本。本轮不包含。

## 2. 覆盖对象

黄金集覆盖一级 Skill 及全部五个二级 Skill：

- `pilot-opportunity`
- `resolving-target-company`
- `researching-bidding-history`
- `analyzing-policy-drivers`
- `mining-customer-pain-points`
- `matching-product-capabilities`

全部引用 Skill 均通过当前严格 `SkillCompiler` 编译；不存在旧格式或默认契约回退。

## 5. 人工专家盲评包

人工评审必须使用随机顺序、隐藏 `expected` 的场景副本。每位专家独立填写：

- 目标主体是否已确认；
- 当前是否存在能力缺口、触发和采购窗口；
- 产品适配是否已验证，是否存在硬阻断；
- Gate 等级与决策；
- 是否允许创建待验证商机假设；
- 主要支持证据、反证和待验证问题；
- 结论质量评分及理由。

在所有专家提交前不得展示系统裁决、另一位专家答案或黄金答案。提交后统一计算系统对专家共识的准确率、专家间一致性、阻断级误判率、G4/G5 精确率和“暂无机会”正确率。

建议门槛如下，需由试点业务负责人正式确认后才成为发布门：

| 指标 | 建议门槛 |
| --- | ---: |
| 已截止、已上线、无需求和硬阻断误升 | 0% |
| G4/G5 精确判断率 | ≥90% |
| “暂无明确商机”正确率 | ≥90% |
| 专家间一致性（Cohen/Fleiss Kappa） | ≥0.70 |
| 关键结论引用正确率 | ≥95% |
| 行动建议人工评分 | ≥80/100 |

## 6. 当前结论与后续动作

WBS-33-36 当前状态为 `PARTIAL（工程基准已验证）`，不能标记为完整专家盲评通过。下一步：

1. 由业务负责人确认试点行业、产品范围和正式门槛。
2. 准备 20～50 家获授权目标企业，以及至少两名独立专家。
3. 对真实搜索、提取、OIG、ProductFit 和报告全链执行盲评，同时记录成本和耗时。
4. 将专家原始评分、分歧裁决和最终结论以不可变评测运行归档。
5. 只有阻断错误为零且其他门槛达标，才允许 WBS-33-36 转为 `VERIFIED` 并进入 WBS-33-39 发布门。
